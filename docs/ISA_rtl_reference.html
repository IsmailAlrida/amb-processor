AMB ISA RTL Reference

Clean HTML view of the RTL contract used by the assembler, simulator, and CPU datapath. The Markdown file remains the working notes source; this page is the Blueprint reading surface.

Core Facts

ItemValue
Instruction encoding width15 bits
Instruction storage width16 bits, stored as 2 bytes
Register file16 registers, 28 bits each
Address model28-bit byte addresses
Normal next instructionIC + 2
Instruction memoryExternal byte-addressed instruction memory
Data memoryExternal byte-addressed data memory, 28-bit little-endian word accesses
byte address N     : [unused][instr[14:8]]
byte address N + 1 : [instr[7:0]]

IC points to byte address N.
Next sequential IC is IC + 2.

Instruction Formats

Register-register and memory [14:8] opcode7 | [7:4] Rb | [3:0] Ra

Ra is the destination. Rb is the source.

Immediate loads and jumps [14:8] opcode7 | [7:0] imm8

Immediate loads write IMR. Jumps use signed 8-bit word offsets.
