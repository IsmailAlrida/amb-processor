Guide

Use the top strip to move between generated module docs, schematic diagrams, ISA notes, and the latest RTL simulation report. SVG pages use this explorer so you can zoom and pan without changing the header or buttons.

CPU DocsThe PyQt CPU Docs button opens this local documentation app in a WebEngine window.
CPU CoreOpens the standalone expanded CPU core diagram from cpu_v1_core.svg.
CPU High LevelShows the overview block diagram from cpu_high_level.svg.
Module DocsGenerated HTML pages describe the ports and module contracts.
Run RTL SimIn the PyQt app, assembles the current program, runs the Verilog testbench, and writes artifacts under build/rtl_sim/... in dev.
Open WaveformOpens the latest .fst or .vcd with the bundled OSS CAD Suite viewer.
Open RTL ReportLoads the latest generated simulation HTML report.
Sample CodeThe sample dropdown loads ready-to-run assembly. The array-sum benchmark also selects the matching benchmark data image for RTL simulation.
