Guide

Use the top strip to move between generated module docs, schematic diagrams, ISA notes, authors, and the latest RTL run summary. SVG pages use this explorer so you can zoom and pan without changing the header or buttons.

CPU BlueprintThe PyQt CPU Blueprint button opens this local architecture and run-results app in a WebEngine window.
Latest RTL RunShows the most recent RTL trace summary. Arbitrary programs are inspection runs; the array-sum sample is the benchmark validation run.
CPU CoreOpens the standalone expanded CPU core diagram from cpu_v1_core.svg.
CPU High LevelShows the overview block diagram from cpu_high_level.svg.
Module DocsGenerated HTML pages describe the ports and module contracts.
Run RTL SimIn the PyQt app, assembles the current program, runs the Verilog testbench, and writes artifacts under build/rtl_sim/... in dev.
Open WaveformOpens the latest .fst or .vcd with the selected OSS CAD Suite viewer. Surfer is the default; GTKWave is available from RTL Options.
Sample CodeThe sample dropdown loads ready-to-run assembly. The array-sum benchmark also selects the matching benchmark data image for RTL simulation.
AuthorsShows the project group information mirrored from the PyQt app.
